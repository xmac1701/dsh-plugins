# My DSH Plugin Collection

This collection is built by DSH and me together.

## Fast Model Selector

[Details](packages/fast-model-selector/README.md)

An intuitive model selector: slide over a model, then click a reasoning effort, and the selection is done.

It comes with favorites for quick switching.

Favorites are stored on the DSH side, so they survive a browser switch.
